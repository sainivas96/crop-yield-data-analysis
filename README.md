# Crop Yield Data Analysis

An interactive Data Science portfolio project using Python, Pandas and Plotly/Streamlit.

## Project goal
Explore agricultural and weather parameters and identify patterns associated with crop yield.

## Features
- Data loading and basic cleaning
- Crop and region filters
- Average yield KPIs
- Crop-wise yield comparison
- Rainfall vs yield relationship
- Fertilizer vs yield relationship
- Region-wise yield comparison
- Correlation analysis
- Filtered CSV download

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the URL shown by Streamlit, normally:
`http://localhost:8501`

## GitHub
Upload the complete project folder, including `app.py`, `requirements.txt`, and `data/crop_yield_data.csv`.

## Deploy
The easiest free deployment is Streamlit Community Cloud. Connect your GitHub repository and select `app.py` as the main file.
